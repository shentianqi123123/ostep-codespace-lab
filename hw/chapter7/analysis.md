# Q1：长度均为 200 的 3 个工作（200，200，200）
FIFO 预测：按到达顺序执行 200 -> 200 -> 200
	 任务1：等待0    周转时间 = 200
	 任务2：等待200  周转时间 = 200+200 = 400
	 任务3：等待400  周转时间 = 400+200 = 600
	 平均响应时间 = 200  平均周转时间 = 400。
SJF 预测：按从小到大排顺序执行 200 -> 200 -> 200
     因为三个任务长度一样，SJF 和 FIFO 完全一样。

# Q2：长度为 100、200、300（100，200，300）
FIFO 预测：按到达顺序执行 100 -> 200 -> 300
     任务1：等待0    周转时间 = 100
	 任务2：等待100  周转时间 = 100+200 = 300
	 任务3：等待300  周转时间 = 300+300 = 600
	 平均响应时间 = 133.33  平均周转时间 = 333.33
SJF 预测：按从小到大排顺序执行 100 -> 200 -> 300
     因为SJF 的执行顺序也是 100 -> 200 -> 300。所以结果和 FIFO 完全一致。

# Q3：用长度为 100、200、300（100，200，300）测试 RR 调度，时间片为 1 
RR 预测：轮流做且每次做1个时间单位
     三个工作一共600，因为有三个工作轮流做，所以三个工作最后完成的时间为（598，599，600），这也是三个工作的周转时间，总共1797。
     平均响应时间 = 1  平均周转时间 = 599
     响应时间非常小，但是周转时间会很大。

# Q4：对于什么类型的工作负载，SJF 提供与 FIFO 相同的周转时间？
当所有工作的长度一样，或者工作的到达顺序已经是从小到大排序的时候，SJF 与 FIFO 的周转时间相同。

# Q5：对于什么类型的工作负载和量子长度，SJF 与 RR 提供相同的响应时间？
当所有工作的长度一样，同时 RR 的时间片等于工作长度时，SJF 与 RR 的响应时间相同。

# Q6：随着工作长度的增加，SJF 的响应时间会怎样？
随着工作长度的增加，SJF 的响应时间也会随着工作长度的增加而增加。长工作必须等待它前面所有更短的作业全部执行完毕。每增加一个更短的作业，长工作的响应时间就增加这个短工作的长度。

# Q7：随着量子长度的增加，RR 的响应时间会怎样？给定 N 个工作的最坏情况？
随着量子长度的增加，RR 的响应时间增加，但周转时间会减少。
N 个工作最坏情况是最后一个工作的响应时间，这个工作需要等待前面 N-1 个作业各运行一个时间片，公式为：(N - 1) * q  / （工作-1）* 长度。
