# Q1 (200, 200, 200)：FIFO 和 SJF 结果一样。
结论：工作等长的时候，SJF 和 FIFO一样。

# Q2 (100, 200, 300)：FIFO 和 SJF 结果一样。
结论：工作如果到达顺序已经按照“最短优先”排好的时候，SJF = FIFO。

# Q3 (RR 时间片为 q=1 的工作 100, 200, 300)：响应时间很低，但是周转时间很长。
结论：RR 优化了响应时间，但是因为频繁切换，周转时间变得很长。 

# Q4：对于什么类型的工作负载，SJF 提供与 FIFO 相同的周转时间？
结论：当所有工作长度相等，或者工作到达的顺序刚好是从短到长的时候。

# Q5：对于什么类型的工作负载和量子长度，SJF 与 RR 提供相同的响应时间？
结论：当所有工作长度相等，同时 RR 的时间片等于工作长度。

# Q6：随着工作长度的增加，SJF 的响应时间会怎样？
结论：因为 SJF 总是优先跑短工作，长工作必须等前面所有短工作跑完，排在它前面的短工作越多，它响应时间越长。

# Q7：随着量子长度的增加，RR 的响应时间会怎样？给定 N 个工作的最坏情况？
结论：量子工作越长，响应越差，周转越好。最坏的情况是排在最后的第 N 个工作的响应时间最差，公式为 (N - 1) * q。
